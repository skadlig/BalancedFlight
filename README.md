This is a fork of Create: Balanced Flight (Angel Ring) as create by Txni.  
Curseforge page: https://www.curseforge.com/minecraft/mc-mods/create-balanced-flight  
Github page: https://github.com/txnimc/BalancedFlight

Since Txni seems to have stopped updating the mod this fork was create to enable myself to keep on playing with it and to be able to include it in mod packs.  
Most of the work to update it to Create 6.0 was made by Sintinium (https://www.curseforge.com/members/sintinium/projects).
Further updated to 6.0.6 by me.
